# AgencyPro WordPress Theme

AgencyPro is a modern, vibrant, and highly customizable WordPress theme designed for digital agencies.

**Version:** 2.2.1
**Author:** Jules

---

## Features

*   **Fully Modular Homepage:** Show, hide, and reorder all homepage sections using a simple "Order" field.
*   **Dynamic Section Backgrounds:** Set a unique background for each homepage section.
*   **Header & Footer Customization:** Control background and text/link colors.
*   **Advanced Typography Controls:** Manage heading font family and text colors.
*   **Custom Post Types:** Easy-to-manage sections for Portfolio, Services, and Testimonials.
*   **AJAX-Powered Portfolio:** Masonry layout with tab-style filtering and a "Load More" button.
*   **Blog with Masonry Layout:** Modern blog layout with a sidebar on single posts.
*   **Dynamic Mobile Menu:** Hamburger icon and menu colors adapt to your chosen header background for high visibility.

---

## Theme Setup

1.  **Package:** Compress the `agencypro` folder into `agencypro.zip`.
2.  **Install:** In WordPress, go to `Appearance > Themes > Add New > Upload Theme` and upload `agencypro.zip`.
3.  **Activate:** Activate the theme.

---

## Configuration (`Appearance > Customize`)

### 1. Required Pages
1.  **Create Pages:** Go to `Pages > Add New` and create:
    *   "Home" (Template: **Homepage**)
    *   "Portfolio" (Template: **Portfolio**)
    *   "Blog" (no template needed).
2.  **Set Static Pages:** Go to `Settings > Reading` and set "Your homepage displays" to "A static page", then assign your "Home" and "Blog" pages.

### 2. Add Content
*   **Services (`Dashboard > Services`):** Add your services. Set a **Featured Image** for display on the homepage and archive page.
*   **Portfolio (`Dashboard > Portfolio`):** Add your projects. Set a **Featured Image** and assign a **Service Type**.
*   **Testimonials (`Dashboard > Testimonials`):** Add testimonials. The post title is the author's name, and the **Featured Image** is their photo.

### 3. Customize Homepage (`Homepage Sections` Panel)
*   **For Each Section:**
    *   **Order:** Enter a number (e.g., 10, 20, 30) to set the display order.
    *   **Display Section:** Check the box to show or hide the section.
    *   **Background Type:** Choose None, Color, Image, or Gradient.
    *   **Client Logos:** Use the 8 available slots to upload client logos.

### 4. Other Options
*   **Header & Footer:** Customize header and footer colors.
*   **Typography & Colors:** Set global text/heading colors and the heading font family.
*   **Theme Options:** Set the main accent color and customize the Service Archive page title/description.
*   **Widgets:** Add widgets to the **Blog Sidebar** and **Footer** widget areas.
